Atlas Platform release notes

Version 7.4.0 — 2026-04-22

The scheduler now supports per-tenant concurrency limits. Setting a limit of zero pauses a tenant without deleting its queued jobs. Queued jobs older than fourteen days are discarded during the nightly compaction.

Breaking change: the deprecated /v1/jobs/submit endpoint was removed. Use /v2/jobs, which requires the tenant identifier in the request body rather than the query string.

Version 7.3.2 — 2026-03-11

Fixed a defect where retry backoff reset after a worker restart, causing failing jobs to retry every second. Backoff state now persists in the job record.

Fixed incorrect timezone handling in the scheduling calendar for regions observing a half-hour offset.

Version 7.3.0 — 2026-02-04

Added an audit log export in newline-delimited JSON. Exports cover up to ninety days and are capped at two gigabytes per request.

Worker memory limits are now enforced by the runtime rather than advisory. A worker exceeding its limit is terminated and its job is retried once on a larger instance class.

Upgrade notes

Upgrading from 7.2 or earlier requires running the schema migration before starting new workers. The migration takes roughly four minutes per million job records and can run online.
